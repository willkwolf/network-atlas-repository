# Cursos y recursos para aprender

| Recurso | Enfoque | Cómo usarlo |
|---|---|---|
| [Learn Network in Python — The New Science of Maps](https://www.thenewscienceofmaps.com/courses/network-py) | Aprendizaje de análisis de redes con Python | Usarlo como punto de partida formativo; verificar el programa, los requisitos previos y las condiciones de acceso actuales. |
| [Awesome Network Analysis](https://github.com/briatte/awesome-network-analysis) | Libros, cursos, software, datos, artículos y grupos de investigación | Recurso de descubrimiento amplio para organizar una ruta de aprendizaje por preguntas y métodos. |
| [NetworkX documentation](https://networkx.org/documentation/stable/) | Construcción y análisis de grafos desde Python | Aprender primero a representar nodos, aristas, atributos y transformaciones antes de seleccionar métricas. |
| [OGB](https://ogb.stanford.edu/) | Datasets/protocolos para aprendizaje automático sobre grafos | Usarlo después de concretar una tarea de ML, baseline, split y métrica; no como primer paso de visualización. |

## Ruta de aprendizaje sugerida

1. Definir nodos, relaciones, dirección y atributos con un dataset pequeño.
2. Aprender componentes, caminos, grados y centralidades, entendiendo sus supuestos.
3. Comparar al menos una visualización interactiva y una figura reproducible.
4. Introducir redes temporales, multicapa o de orden superior solo cuando la pregunta lo requiera.
5. Pasar a graph ML después de formular una tarea predictiva y un protocolo de evaluación que evite leakage.

El repositorio registra los recursos; no certifica la calidad pedagógica de cursos ni sustituye la revisión de prerrequisitos y programa.
